## Featured Projects

- **[AdversIA](https://github.com/ribasgiovanna/AdversIA)** &middot; [live demo](https://adversia.vercel.app) (team project) - AI assistant for Family Law attorneys that reads the case as the opposing counsel would and flags contradictions, evidence gaps and likely hearing questions. Built at the OAB/PR 2026 Citizenship Hackathon and shipped after it: a 7-step versioned prompt pipeline, serverless Python endpoints on Vercel, a 32-case demo mode and technical PDF output. My part: the back end and the front end.
- **[Cobot](https://github.com/ribasgiovanna/cobot)** - Discord bot that publishes Coffee & Code events and deletes each post when registration closes. Python and SQLite, running 24/7 under systemd on an Oracle Cloud Always Free VM (~32 MB of RAM), with an operations manual for whoever maintains it next.
- **[DATASUS Hemotherapy PR](https://github.com/ribasgiovanna/datasus)** (team project) - RPA extraction (Selenium) of hemotherapy data from the DATASUS TabNet, with 3 parallel workers, checkpointing, pandas treatment and a Streamlit dashboard. My part: the project idea and the extraction and treatment modules.
- **[Pibble Express](https://github.com/ribasgiovanna/pibble_express)** (team project) - Django delivery-management system with authentication, ADM/FUNC access levels, CRUD and a REST API. My part: proposing Django as the framework, the Employees module and its integration with Deliveries, CPF/CNPJ registration and the admin dashboard.
